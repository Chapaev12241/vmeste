# Рядом / Vmeste

Приложение iOS 17+: карта двух участников, одноразовое приглашение, аватарки, пауза, отключение пары и виджет с последней полученной позицией. SwiftUI + WidgetKit, сервер Python + SQLite. Координаты не отправляются в GitHub.

## Состояние

Сервер проверяется интеграционным тестом: регистрация, приглашение, обмен координатами, изоляция третьего пользователя, пауза, отключение и удаление. GitHub Actions собирает неподписанную IPA. Проверка на двух физических iPhone пока не выполнена. Необходим отдельно работающий HTTPS-сервер.

## Сервер

На своём сервере с Docker: `cd server && docker compose up -d --build`. Данные в постоянном Docker volume. Проксируйте HTTPS-домен на `127.0.0.1:8080` через Caddy/Nginx. Пример Caddy: `your-domain.example { reverse_proxy 127.0.0.1:8080 }`. Откройте входящий 443. GitHub Actions не служит постоянным сервером. Не используйте GitHub Pages для API.

Для временной локальной проверки: `python3 server/server.py` (HTTP; приложение намеренно принимает только HTTPS). Не публикуйте базу SQLite, ключи и координаты. Сервер доверенный, видит координаты; сквозного шифрования нет. Хранится только последняя позиция; пауза удаляет её, отключение пары удаляет обе позиции.

## Установка через AltStore

1. В Actions дождитесь зелёного Build Ryadom, скачайте артефакт Ryadom-unsigned и извлеките IPA.
2. Установите IPA через AltStore на обоих телефонах. Сохраните расширение виджета при установке. AltStore должен подписать приложение и расширение с одной App Group; если аккаунт или способ подписи не поддерживает App Groups, виджет не сможет читать данные. Это требует проверки на ваших устройствах.
3. Укажите один HTTPS-адрес сервера на обоих телефонах, нажмите «Подключиться».
4. Один создаёт код (10 минут), второй вводит его. После подключения каждый включает свою геопозицию.
5. Для обновлений вне приложения разрешите геопозицию «Всегда». Добавьте виджет «Рядом» через экран добавления виджетов iOS.

Бесплатная подпись Apple имеет ограничения срока действия, App ID и расширений; обновление подписи выполняется через AltStore. Для TestFlight нужна отдельная настройка Apple Developer.

## Обновления и батарея

При открытом приложении позиция партнёра запрашивается раз в 30 секунд. Геопозиция телефона обновляется при существенном перемещении (Core Location significant changes), без постоянного GPS и Live Activity. Точность и задержка зависят от iOS и сети. После принудительного закрытия пользователем фоновые события могут не приходить до следующего открытия.

Виджет показывает кеш последнего ответа сервера, полученного приложением, и возраст позиции. Сам виджет не опрашивает сервер; это не гарантия живого обновления в фоне. Для свежих данных откройте приложение. Системный индикатор геолокации контролирует iOS.

## Сборка локально

Нужны Xcode и XcodeGen. `xcodegen generate`, затем открыть Ryadom.xcodeproj. Выбрать Signing Team для обоих targets и зарегистрировать уникальные bundle IDs и общий App Group, заменив `com.personal.ryadom` / `group.com.personal.ryadom` в project.yml и Shared/Models.swift. Шрифт Docker One взят из предыдущего проекта; права на распространение нужно учитывать перед публичным релизом.

`python3 -m unittest discover -s server -v` — серверный тест.
